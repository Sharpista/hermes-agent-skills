# Hermes test scenarios

Para cada requisito, cubra caminho feliz, entradas inválidas, limites, estados vazios, erro de dependência, permissões, concorrência quando relevante, reload/persistência e comportamento responsivo para UI.

Escreva cenário, pré-condições, dados, passos, resultado esperado e evidência. Marque o tipo de validação: unitário, integração, browser, manual ou operacional. Use os cenários para alimentar `verification-planning`, TDD e `hermes-bugbash`; não gere casos redundantes apenas para aumentar cobertura.
