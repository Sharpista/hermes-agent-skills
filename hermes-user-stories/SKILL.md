# Hermes user stories

Escolha o formato adequado:

- usuário: “Como [usuário], quero [ação], para [resultado]”;
- job story: “Quando [situação], quero [motivação], para [outcome]”;
- WWA: Why, What, Acceptance.

Cada item deve ser pequeno, independente quando possível, negociável, útil, estimável e testável. Inclua fora do escopo, dependências, casos de erro e critérios de aceite observáveis. Não confunda tarefa técnica com valor do usuário; vincule ambas quando necessário.
